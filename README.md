# 🎬 Amazon Prime Video Dashboard | Tableau

## 📌 Project Overview

This project presents an interactive **Amazon Prime Video Dashboard** developed using **Tableau**. The dashboard provides valuable insights into Amazon Prime's movie and TV show catalog by analyzing genres, ratings, release years, countries, and content distribution.

The objective of this project is to demonstrate data visualization, storytelling, and dashboard design skills using Tableau.

- Drama
- Comedy

- Kids

- TV Shows

---

### 🍩 Shows by Type

Donut chart representing the proportion of:

- Movies
- TV Shows

---

### 📅 Shows by Release Year

Area chart illustrating the growth of Amazon Prime content over time.

---

## 📌 Dashboard Insights

- Drama is the most common genre available.
- Movies significantly outnumber TV Shows.
- The number of titles increased rapidly after 2010.
- Amazon Prime hosts content from multiple countries worldwide.
- TV-14 and 13+ ratings contain a large portion of available content.
